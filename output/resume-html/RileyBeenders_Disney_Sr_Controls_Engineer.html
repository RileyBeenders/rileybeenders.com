BulkSSH | Windows desktop app, open source at github.com/RileyBeenders/BulkSSH
October 2026 - Present

TypeScript, Electron, Node.js, SSH

Problem: Testing ExtrusionStudio's Pi kiosks meant repeating the same commands on every Pi, one SSH window at a time, after every change to the image.

  • Opens every device in a grid of live terminals, mirrors keystrokes to every ticked device, and broadcasts a command with each device's output and exit code, so a change to the Pi image is tried on every Pi in one pass.
  • Requires confirmation before risky commands such as reboot or rm -r reach several devices, never accepts host keys silently, and reconnects dropped connections by itself; released as an installer and a portable executable.
  • Simulates SSH devices for development, so the app can be tried without hardware; saved passwords are optional and encrypted with the Windows account.
