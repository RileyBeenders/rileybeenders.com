# Design Guidelines

One of several repository agent procedures — see the repo-root `CLAUDE.md` for the set.

Two reference design-token systems live here, switched by color-scheme mode. Start at [`DESIGN.md`](DESIGN.md) — it routes to whichever of [`design-light.md`](design-light.md) or [`design-dark.md`](design-dark.md) matches the mode being built, and explains how to use them together (pull tokens from the matching file only, don't mix across modes within the same mode; both share a "photography-first, minimal chrome" philosophy so a component should still read as one coherent product across modes).

**These files are reference token/component libraries, not a description of the site's own layout, type, or component markup.** The live system is **Clean Bench** (since the 2026-11-09 redesign): `app/(site)/bench.css` with tokens derived in `lib/palette.ts` (`deriveSheetTokens`, a name kept from Blue Sheet) from the active `clean-bench` preset in `lib/palettes.ts`. Everything is a tile: white rounded tiles on a pale grey-blue ground under a frosted glass nav, a soft blue bloom behind the top of the page, one cobalt from `--tint` to `--accent-fill` (which deepens in dark mode), Instrument Sans for headings and body with Azeret Mono for small labels, the monogram, the one easing curve, and project tiles that morph into their dialog. It is specified in the repo-root **`DESIGN.md`** (machine-readable tokens plus named rules, generated by `$impeccable document` and read by `impeccable`'s detector) and narrated in the vault at `.obsidian/rileybeenders.com Notes/05 Styling and Design/Design System (Clean Bench).md`. Read the root `DESIGN.md` first for any styling task; come here only for the Tesla/Bugatti source material. Colors are where the two used to meet: the **Electric** palette preset (`lib/palettes.ts`, the live preset under the previous Blueprint Press system and still selectable in the Studio) pulls its light-mode canvas/ink/accent straight from `design-light.md` (Tesla) and its dark-mode canvas/ink from `design-dark.md` (Bugatti). The Clean Bench preset (and the earlier Blue Sheet one) is not derived from either file.

The router file in this folder is also named `DESIGN.md`; it is **not** the design system `impeccable` resolves (that is the one at the repo root). It only picks between the two reference files below.

## When this applies

Any task that touches visual styling: a new or restyled component, a light/dark toggle (including the in-progress Studio theme/font settings), color/typography/spacing decisions, or an explicit ask to check "the design guidelines" for a mode.

## Related procedure

`vault-sync` (`.claude/skills/vault-sync/SKILL.md`) still applies on top of this — a change under `design/`, `.claude/skills/design-guidelines/`, or the site's own CSS updates the vault's styling note independently of which reference file this skill points you to.
